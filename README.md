Proyecto 13 - Sistema de Gestión de Farmacia

Descripción

Sistema para controlar el inventario de medicamentos, registrar ventas,
gestionar recetas médicas y generar alertas cuando un producto esté
próximo a vencer o se encuentre por debajo del stock mínimo.

Usuarios

- Administrador
- Farmacéutico
- Cajero

Módulos principales

- Gestión de usuarios
- Catálogo de medicamentos
- Inventario
- Gestión de lotes
- Control de vencimientos
- FEFO
- Registro de ventas
- Gestión de recetas
- Alertas
- Reportes

Metodología

El proyecto utiliza la metodología ágil **Scrum**, organizada en tres Sprints.

### Sprint 1
- Usuarios
- Medicamentos
- Inventario
- Stock mínimo

### Sprint 2
- Ventas
- Recetas
- Lotes
- Control de vencimientos
- FEFO

### Sprint 3
- Alertas
- Reportes
- Validaciones
- Pruebas
- Documentación técnica

##  Lotes y FEFO

Cada medicamento puede tener varios lotes, y cada lote posee su propia
cantidad y fecha de vencimiento.

La estrategia FEFO (First Expired, First Out) permite utilizar primero
el lote cuya fecha de vencimiento sea más próxima.
